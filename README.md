# Internet Mood Ring

I wanted to see what the internet feels like.

So this is a map where people click how they feel, and the color of each country changes based on that.  
Nothing complicated — just a way to turn emotions into something you can actually look at.

Right now it’s not truly live yet. The data is fake just to show how it could work.

## What it does

- world map with colors based on mood  
- click a mood → it updates a country  
- basic stats per country (mood, votes, last updated)  

## What I want it to become

- real people submitting moods  
- countries updating in real time  
- a way to see how the world feels at any moment
